# Eliminate guards implied by the ordered dispatch prefix

Expressions remain mathematical strings compatible with SymPy. JSON files
record evidence and compiler state. This advances coordinate 2, position zero,
one token. It does not complete the input domain, other coordinates or tokens.

Each guard is simplified in its own frozen prefix before path distribution.
When a later Piecewise arm is reached, every preceding original path condition
is false. `OrderedGuardPruner` combines those facts with the current path's
preceding guards and asks SymPy's Boolean SAT solver whether negating the next
guard is impossible. Only a proved implication removes that guard. The kept
guards and arms retain their original order and lazy evaluation.

Compiler propositions represent identical expanded guard strings, without
opening floating operations. A streaming SHA256 identifies candidates; an
additional comparison of actual expanded bytes establishes identity, including
hash collisions. Atom/node budgets retain all original conditions when exhausted.
The SAT context is compiler-only proof data. Each numerical string already
passed factor/simplify in its own prefix; the actual combined emitted expression
passes factor/simplify to stability again before atomic publication.

The broad mixed-sign region has X1 in [-65504, -0.03125], X2 in [0.03125, 65504].
All 28 paths are preserved. Forty-six redundant guards are removed, reducing
30,039,520 serialized characters to an emitted 22,507,034 characters (25.08%).
The file uses a bounded 32 MiB artifact/CAS budget and 480-second worker deadline.
Fresh compilation completes in 241.83 seconds. The prior 16 MiB attempt produced
no complete file, so its stopping time is not a comparable completion benchmark.

`broad.expr` contains only original input variables, concrete checkpoint weights,
elementary operations and explicit conditions. It has no compiler aliases or
pending rounding/sqrt/activation primitives. Original Torch CPU readback first
checks 16,388 corners/random inputs, then exhausts all 462,422,016 finite Half
pairs in this region: zero bit mismatches. Exhaustive verification takes 143.34
seconds, separately from compilation. This is real artifact parity, not a bound
or expansion estimate, and does not establish full-coordinate parity.

The worker was observed using about 4.6 GiB of resident memory. `memory.json`
contains one-second samples attached late in the run, so its maximum is not a
complete-run peak. One large compiler worker was used; no CUDA or parallel speedup
is claimed by this change. The initial recursive Boolean minimization was
profiled and replaced by direct implication proofs over the already stabilized
predicates; code-changing experimental runs were discarded by identity checks.

Twelve coherent-path tests include signed zeros, unsafe later predicates, hash
collisions, budget fallback, atomic admission and native normalization parity.
All 34 SymPy integration tests pass with the actual checkpoint configured.
The general suite uses the previous environment: 628 tests, 570 pass, 15 unchanged
failures, 43 skips. The historical test map is preserved and extended.

The new frontier reuses only audited geometric partitions. Source changes reset
old numerical evidence; only this freshly emitted and exhaustively checked
region is admitted. The remaining 3,568,304,128 input pairs are pending under
